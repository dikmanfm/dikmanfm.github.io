# concepts/_base

עותק קפוא של שכבת "קונסולת הגרפיט" (העיצוב של phase-1) שעליה בנויים קונספטים A, B ו-C.

העיצוב הראשי ב-`main` עבר ל-"הקול הוא הממשק" ומחק את הקבצים האלה מהשורש, אז הקונספטים מחזיקים עותק משלהם
כדי שימשיכו לעבוד בלי לגעת באפליקציה הראשית. הם עדיין משתמשים בקבצים המשותפים מהשורש:
`js/config.js`, `js/zmanim.js`, `js/schedule.js`, `js/demo-audio.js`, `data/episodes.json`, `vendor/`, `fonts/`, `icons/`.

כשייבחר קונספט, הוא יוטמע באפליקציה הראשית והתיקייה הזו תימחק.
